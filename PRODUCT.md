# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Stack

Parcel 2, static HTML for the header, React for the `#projects` section. Published on GitHub Pages under `thcol.in`.

## Users

Two visitors in equal parts:

- a developer or a curious person coming from a GitHub repository (sensorr, gmca, oleoo) who wants to see what else Thomas builds;
- a client or a recruiter evaluating a Lead Developer before a mission or a call.

## Purpose

Present Thomas Colin and what he builds. The header says who he is and how to reach him; the projects section shows the work, each project in its own world, with a live demo where one can run in the page.

## Success

A visitor leaves a project band toward that project: its site, demo, GitHub repository or package registry. Projects without a public release (NFR, Coming soon) carry no link. The header's mail address is the only contact.

## Content and evidence

- Released: sensorr, gmca (gamepad-media-center-aggregator), oleoo, react-responsive-virtual-grid.
- Coming soon: cinetropes, no link.
- NFR (not for release): teevy, Workflow & Obsidian, no link.
- 3D printing: top-fan, nas.
- Archived: nipper, boaty, chrome-download-quicklook-extension, scene-release-parser-php, senscritique-api.

Star counts, versions and figures come from the repositories; nothing is invented.

## Brand commitments

- The header (wordmark `thcolin`, photo, links) is fixed.
- Site language is English.
